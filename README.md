# 问而帮 Frontend（H5 Demo）

Vue3 + Vite + TypeScript + Pinia + Vue Router。

分层对齐 uni-app 参考项目（`pages` / `services` / `stores` / `constants`），黑客松优先 H5 演示；后续可迁回 uni-app 小程序。

## 启动

```bash
cd frontend
pnpm install   # 或 npm install
pnpm dev
```

浏览器打开提示地址（默认 `http://127.0.0.1:5173`）。开发服务器已代理 `/api` → `http://127.0.0.1:8080`。
